The problem

Why InkSoft WordPress sites feel slow.

The usual way to put InkSoft on WordPress is to load InkSoft's entire storefront inside your page and hide its header and footer. It looks native, but every visit loads two websites, and it quietly breaks when InkSoft changes its layout.

The usual setup

  • Your whole InkSoft store loads inside a frame on every page
  • Pages wait on InkSoft, so a slow day for InkSoft is a slow day for you
  • Code is often scrambled, so nobody but the original developer can fix it
  • When a cache job gets stuck, whole categories can go empty with no warning
  • Search engines see a frame, not your products

The Second Set way

  • Categories and products are real pages on your own site
  • Browsing reads a saved copy of your catalog, so it loads instantly
  • Every file is plain, commented code you own
  • A dashboard shows every category and flags empty ones in red
  • Only cart and checkout use InkSoft, where InkSoft's logic belongs

Questions

InkSoft and WordPress, answered.

Can InkSoft work with WordPress?

Yes. InkSoft publishes a public catalog API, so a WordPress site can show your InkSoft categories and products on its own pages. Cart, checkout and the online designer stay on InkSoft, so your pricing, coupons, tax, shipping and order flow keep working exactly as they do today.

Why is my InkSoft WordPress site slow?

Most InkSoft WordPress setups load InkSoft's whole storefront inside the page, or call InkSoft live every time someone opens a category. Either way the visitor waits on a second website. Our plugin saves your catalog on your own site ahead of time, so browsing pages load from your server instead.

Do I need an InkSoft API key?

No. The plugin reads InkSoft's public catalog, which only needs your numeric store ID. We find that ID for you during setup.

What happens when I add or change products in InkSoft?

The catalog refreshes itself every hour. If you want a change to show up right away, click Refresh catalog now in the Second Set dashboard inside WordPress.

Will I be locked in to Second Set?

No. Every file in the plugin is plain, commented code, not scrambled or hidden. You or any developer can open it and see exactly what it does.

Do you set up the InkSoft storefront too?

Yes. Store setup is part of the work: categories, products, decoration methods, pricing, color availability, shipping, tax and payments, plus the one-time script InkSoft needs for the embedded cart.

How much does an InkSoft WordPress site cost?

It depends on the size of your catalog and how many custom pages you need. Send us your store link and we will come back with a fixed quote, usually the same day.
